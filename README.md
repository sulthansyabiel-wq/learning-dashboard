# 📘 EduSmart - Media Pembelajaran Interaktif

## 📋 Deskripsi Proyek
Dashboard media pembelajaran berbasis web dengan fitur dark mode, animasi hover, dan sistem XP.

## ✨ Fitur Unggulan
- 🌙 Dark Mode Toggle
- 🎨 Animasi Hover pada Tombol
- 📱 Responsive Design
- 📊 Sistem XP dan Level
- 📚 Materi Pembelajaran

## 🛠 Teknologi yang Digunakan
- HTML5
- Tailwind CSS
- JavaScript
- Git & GitHub
